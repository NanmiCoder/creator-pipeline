# 实测与已知边界

日期：2026-09-07。机器：**Apple M5 Pro，64 GB 统一内存，macOS 26.5.2，arm64**。参考是本人已有口播的 15 秒单人片段，仅在本机使用。公开仓库包含测试文案、样例代码和脱敏结果，不包含这段录音或克隆产物。

这不是跨设备排行榜。不同模型、暖缓存与句长影响时间；没有把单机短样本结果写成所有用户的实时或低内存保证。

## 实际合成

| 测试 | 结果 | 计时口径 |
|---|---|---|
| Nano CPU 4 线程，初次短样本 | 8.08 秒音频；合成 2.874 秒；峰值 RSS 3.91 GiB | 合成不含 13.872 秒导入、4.608 秒模型加载；进程约 21.354 秒；不含下载 |
| Nano 重用模型与参考编码 | 两句 4.24 / 3.92 秒；合成 0.822 / 0.740 秒；峰值 RSS 3.52 GiB | 暖进程，另记录加载与参考编码，不与上一行当作优化 A/B |
| Nano 公共 run.py，六句 136 字 | 首轮成品 28.146 秒；synth 阶段 8.7 秒 | 已有模型缓存，阶段耗时含该进程模型加载，不含安装/下载/后续拼接 |
| Nano 只重试第 2 句 | **1 pending / 5 cache**；synth 阶段 4.2 秒；最终 **28.386 秒** | `--segment-seed 2:3`，保留其他句子缓存，重建同源 WAV/MP3/SRT |
| Qwen MLX，同稿六句 | 成品 **31.3535 秒**；synth 阶段 9.6 秒 | 已有模型缓存；与 Nano 有不同语速，不可只比耗时就说质量相同 |

模型权重与代码版本见 [选型记录](TTS-BACKENDS.md)。MP3 参考输入也已在 Nano 前向测试中验证。

## 保留失败，检查真实内容

公开样本：[script.md](../examples/first-video/script.md)。本地辅助 ASR 使用 faster-whisper 1.2.1 / large-v3-turbo / CPU int8；删除标点与空白后对照原文，不把 ASR 转写替换成字幕源文案。

- Nano 首轮第 2 句“声音克隆…在线套餐”出现 ASR 转写偏差；初次 WAV 结构验证通过仍不足以交付。
- 全文换 seed 1 后，第 2 句匹配，但第 3 句又出现“时间戳/时间轴”的转写偏差。这证明**全文重做可能破坏原本可用的段落**。
- 最终保留首轮其他五句，只把第 2 句改用 seed 3。最终 Nano 全稿 ASR 规范化文本与原稿一致；Qwen MLX 六句也一致。
- 这只能说明本次 ASR 文本核对通过。没有盲听对照、音色嵌入评估或自然度评分，不能宣称已经证明声音与真人一样。

脱敏机器可读结果：[speech-results.json](evidence/speech-results.json)。用户换一段参考、文案或设备应先试代表性短段，seed 3 不是通用修复配方。

## 独立故障审查

独立前向审查使用正式安装在 site-packages 的 Nano 与真实模型，测试数据放独立目录。已发现并修复：

| 问题 | 修复后的实测行为 |
|---|---|
| 给 Nano 传了上游不存在的参数 | 固定 commit 的公共安装入口直接合成成功 |
| 修改原稿后旧交付仍能验证 | build、verify、网页 import 都拒绝旧清单 |
| WAV 头损坏导致恢复直接崩溃 | 自动重做损坏的 1 段，其他段保留 |
| 导入器接受被篡改的时长、缺 start、假 timing_method | 读取实际 PCM 帧并核验有限值、帧边界与方法，三种损坏均拒绝 |

此外已实际执行：不变输入全缓存、只改一段只重做该段、替换参考使全部失效、对真实生成进程发 SIGTERM 后断点恢复、整个产物目录搬迁、中文/空格路径导入。中断发生时缺失段阻止拼接；旧清单也不会冒充新稿成品。

仓库内 `python3 -m unittest discover -s tests -v` 包含 **15 项测试**，不用模型或云账号即可运行，覆盖文件/时间契约、文案保留、缓存失效与单句种子持久化。MiniMax 只核对当前 CLI help 和模拟 speech 调用参数，没有真的上传或消费云端额度；登记声音的 HTTP 流程尚未做线上验证。

## 网页交接与发行

六句样例通过实际 WAV 与 SRT 导入并生成时间轴，真实 TypeScript、时间轴/步数/前缀检查 **7 PASS / 0 SKIP**，生产构建完成。模板测试与 CI 不代替实际样例的画面验收。

Ego Lite 浏览器查了 7 个关键时间点并完成全片播放。第一次无捕获的后台测试出现最多约 0.98 秒画面采样滞后，不能当作流畅性通过。随后使用可见页面与真实 CDP 捕获会话重测：306 次观测覆盖 step 0–5，音频与画面最终同为 28.386 秒，观测到的最大时钟差为 **12.82 ms**，无音频错误；捕获 684 张帧。这个数是该次观测值，不能宣称所有浏览器“零漂移”或保证 60 fps。

画面复查还调整了输入卡片到网页窗口的空间关系，避免转场后克隆配音卡被遮住。README 图片来自最终场景。个人声音的预览 MP4 只在本机保留。

新增单句重试也经历独立复查：普通 synth 和完整 run 持久保留已选 seed 与音频 SHA；只有显式 clear 才恢复默认，避免已修读音在续跑时回退。

`npx skills` 的 local discovery 应恰好发现两个技能。发行验证使用隔离目录的 Codex/Claude Code 项目级 `--copy` 安装，不覆盖维护者已有的全局技能。参考声音、密钥、模型、字节码和个人路径在提交前检查排除。
