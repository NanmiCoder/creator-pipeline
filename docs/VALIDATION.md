# 实测与已知边界

日期：2026-09-07。机器：**Apple M5 Pro，64 GB 统一内存，macOS 26.5.2，arm64**。参考是本人已有口播的 15 秒单人片段，仅在本机使用。公开仓库包含测试文案、样例代码和脱敏结果，不包含这段录音或克隆产物。

这不是跨设备排行榜。不同模型、暖缓存与句长影响时间；没有把单机短样本结果写成所有用户的实时或低内存保证。

## 本次修订：Qwen 默认、16:9 外框与视觉样片

用户反馈后，默认模型改为 **Qwen3-TTS**，不再用 Nano 的 CPU 可运行性代替听感要求。Apple Silicon 自动选择 MLX，其他平台选择官方 PyTorch。`setup.py` 与 `run.py` 都使用同一默认选择函数；Nano 必须显式指定。

- 默认 setup 在本机解析为 mlx；不传 provider 的完整 run 实际生成了 31.3535 秒配音，synth 阶段约 7.8 秒（已有模型，不含安装/下载）。PCM 与前次已做 ASR 核对的 Qwen 样本逐文件一致。
- 新增平台路由测试，Python 测试合计 16 项。模拟平台测试不等于 Windows/CUDA 实机测试。
- 1920×1080、1440×900、2560×1080、480×270 四种窗口下，Manual/Auto/Review 三种模式均实际检查，共 12 个组合；矩形比例为 16:9，四周保留外边距，同视口切模式尺寸一致。1440×900 窗口里舞台为 1280×720，位置 x=80、y=90。[几何记录](evidence/revision-geometry.json)
- 舞台改为直角内容区；框线、角标和控制条在内容区外。录屏沿框线框选，不把浏览器外边距录入视频。
- 新样片全程实际捕获 1520 帧，336 次观测覆盖 step 0–5，最大音频/场景时钟差约 **19.15 ms**；最终音频 31.3535 秒，场景 31.354 秒（SRT 毫秒舍入），没有捕获到音频错误。按真实舞台裁出 1280×720 的本地 MP4 并查看视频帧。
- 24 秒 → 5 秒 → 24 秒的标题、对象样式和 MG 几何一致；系统减少动态效果时，24–25 秒装饰运动与主体变换保持稳定，功能性播放头继续跟随时间。[播放与验帧记录](evidence/revision-playback.json)
- 样片改用深色舞台、无衬线大字、分层文案/声音卡、真实配音振幅、SRT 片段和连续时间轴。固定主题不是所有未来项目的强制风格；视觉是否合用户偏好仍以实际样片反馈为准。
- 公共验收规则已覆盖 SKILL、EVALUATION、CRAFT、MOTION、脚手架提示及生成的 BRIEF，使用用户指定或本机可用的浏览器 skill，不限定 Ego。当前机器遵循本地偏好用 Ego 实测；并未声称已经逐一运行所有浏览器工具。

下面保留首版试验与失败记录，Nano 数字属于历史结果，不代表当前默认模型。

## 独立故障审查

独立前向审查使用正式安装在 site-packages 的 Nano 与真实模型，测试数据放独立目录。已发现并修复：

| 问题 | 修复后的实测行为 |
|---|---|
| 给 Nano 传了上游不存在的参数 | 固定 commit 的公共安装入口直接合成成功 |
| 修改原稿后旧交付仍能验证 | build、verify、网页 import 都拒绝旧清单 |
| WAV 头损坏导致恢复直接崩溃 | 自动重做损坏的 1 段，其他段保留 |
| 导入器接受被篡改的时长、缺 start、假 timing_method | 读取实际 PCM 帧并核验有限值、帧边界与方法，三种损坏均拒绝 |

此外已实际执行：不变输入全缓存、只改一段只重做该段、替换参考使全部失效、对真实生成进程发 SIGTERM 后断点恢复、整个产物目录搬迁、中文/空格路径导入。中断发生时缺失段阻止拼接；旧清单也不会冒充新稿成品。

仓库内 `python3 -m unittest discover -s tests -v` 首版包含 **15 项测试**，不用模型或云账号即可运行，覆盖文件/时间契约、文案保留、缓存失效与单句种子持久化。MiniMax 只核对当前 CLI help 和模拟 speech 调用参数，没有真的上传或消费云端额度；登记声音的 HTTP 流程尚未做线上验证。

## 网页交接与发行

六句样例通过实际 WAV 与 SRT 导入并生成时间轴，真实 TypeScript、时间轴/步数/前缀检查 **7 PASS / 0 SKIP**，生产构建完成。模板测试与 CI 不代替实际样例的画面验收。

Ego Lite 浏览器查了 7 个关键时间点并完成全片播放。第一次无捕获的后台测试出现最多约 0.98 秒画面采样滞后，不能当作流畅性通过。随后使用可见页面与真实 CDP 捕获会话重测：306 次观测覆盖 step 0–5，音频与画面最终同为 28.386 秒，观测到的最大时钟差为 **12.82 ms**，无音频错误；捕获 684 张帧。这个数是该次观测值，不能宣称所有浏览器“零漂移”或保证 60 fps。

画面复查还调整了输入卡片到网页窗口的空间关系，避免转场后克隆配音卡被遮住。README 图片来自最终场景。个人声音的预览 MP4 只在本机保留。

新增单句重试也经历独立复查：普通 synth 和完整 run 持久保留已选 seed 与音频 SHA；只有显式 clear 才恢复默认，避免已修读音在续跑时回退。

`npx skills` 的 local discovery 应恰好发现两个技能。发行验证使用隔离目录的 Codex/Claude Code 项目级 `--copy` 安装，不覆盖维护者已有的全局技能。参考声音、密钥、模型、字节码和个人路径在提交前检查排除。
