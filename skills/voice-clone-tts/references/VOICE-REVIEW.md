# 比较克隆音色

选型目标是让这位用户的配音像本人、读得对、适合其作品，不是证明某供应商普遍最好。

1. 从用户原声选干净、完整的参考短段，所有供应商用同一段。参考转写必须精确对应；Qwen 优先使用音频加转写的 ICL，MiniMax 可增加不足 8 秒的匹配 prompt。分别记录这些条件，不能假称模型接口完全相同。
2. 另选至少三段未参与克隆的原声，覆盖技术专名、口语问句、结尾节奏。保留原声并用同一文案在各后端合成；记录模型与版本。至少再生成一轮，保留全部结果，避免只挑最好的一次。
3. 试听副本仅调恒定增益并限制峰值，避免响度偏好；不改速度、音高，不加压缩。提供隐藏供应商名称的试听入口，记录用户选择与是否已揭晓标签。不能把单人偏好测试写成双盲实验。
4. 检查每段实际读音、漏读、重复、停顿和中英混排。ASR 只辅助排查，原声也要跑同一 ASR 作为对照；不要按 ASR 猜测覆盖原稿。
5. 如用声纹模型，优先与相同文案的未见原声比较，至少两种独立编码器，并报告原声之间的基准。与克隆输入本身的接近程度单独列出。余弦不是校准概率，分数接近不能强行宣称胜负。
6. 用户听感与模型分数不一致时如实保留，两者衡量的内容不同。个人默认以用户确认的声音为准；公共默认说明这只是有限样本选择，保留替代方案。

音频、私人音色 ID、参考路径、账号凭据留在用户项目与个人配置中；公开报告只保留脱敏方法、数字和限制。
