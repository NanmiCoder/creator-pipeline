# Creator Pipeline 默认模板

运行 `npm run dev`，首页就是连续 MG 场景的逐拍演示。点击“下一步”或按 → / 空格推进；← 回退，“重播”回到开头。默认 creator-dark 主题。

- `/` 或 `?review=1&t=0&steps=1`：21 个动作拍，逐拍播放后停住。
- `?auto=1`：点击起播后，约 31 秒无声连播，到尾帧停止。
- `?manual=1`：点击舞台/方向键按六段口播推进，每段内部动作连续展开并停住。
- `?review=1&t=20`：确定性查看指定秒的画面，适合截帧。

舞台始终为 1920×1080 等比缩放，录屏框选 `.stage-frame` 的 16:9 内容区域；提示和控制条都在框外。小于 250px 高的窗口隐藏外部控件，可使用键盘。

未接入配音时，顶端会显示“模板演示 · 无声”，波形与时间区间为示意。模板不含个人录音，也不会请求不存在的音频、下载模型或自动调用付费服务。

## 用自己的内容制作

`src/chapters/01-pipeline/` 是默认场景的唯一实现：`chapter.tsx` / `chapter.css` 管构图与对象转换，`beats.ts` 管句内动作，`timing.ts` 管六段演示区间，`waveform.ts` 是可替换的示意波形。

1. 先准备最终音频与 SRT，导入并按内容写 `../plan.md`。然后 `npm run gen` 生成真实时间轴和章内 timing；整段音频以 `audio.currentTime` 驱动画面，无声预览不会覆盖真实音频失败。
2. 新文案需要新的章节、动作谱与画面。同步注册 `src/registry/chapters.ts`，移除默认注册的 `previewTiming`，再删除不再使用的示例。不要只替换六句话却沿用不相干的“文案→声音→网页”镜头；动作数量按内容确定。
3. 若保留同名章节，注意 gen 会保留已有 `narrations.ts`，先备份并同步新稿。真实波形应从最终 PCM 提取，并将 `waveformIsIllustrative` 设为 false；没有实测波形就保留示意标注。
4. `npm run check`、`npm test`、`npm run build` 后，用本机可用浏览器检查逐拍、回退、连续播放和 16:9 框选边界。录制真实作品用 `?auto=1`，不加 review/mute。

保留已验收的构图层次、主体连续性、句内多拍推进与转场质量。六段故事和 21 拍是这个演示的编排，不是其他题材的固定结构。
