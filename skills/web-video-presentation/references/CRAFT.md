# 把口播演出来

输入：本章 BRIEF、主题 token、全片视觉约定。先识别观众要理解的关系，选主体和动作，最后才放文字。

## 镜头选择

| 口播任务 | 主视觉与可见变化 | 常见失败 |
|---|---|---|
| 原因→后果 | 同一个对象被移动、扩大、阻挡、分裂；路径带着它去结果 | 四张写着步骤的卡依次淡入 |
| 多对象比较 | 同尺度对象并置；焦点前推，结果翻面，已知状态留下 | 每个对象换一页，无法横向比较 |
| 数据/规模 | 有口径的长度、数量或面积变化，关键值钉住 | 数字滚动却没有比较基准 |
| 工具操作/实测 | 真实截图或录屏局部放大，指针/高亮落在证据上 | 手绘“成功终端”冒充成功证据 |
| 系统/流程 | 零件组装、连线绘制、消息沿路径运动、阻断或旁路 | 小图标配长解释，看完仍不懂机制 |
| 判断/转折 | 前镜头物体延续、局部反转、短句落版；必要时干净硬切 | 每次都有扫光、全屏模糊和标题飞入 |

**删掉正文再看：观众还看得出“谁变成了什么”吗？** 如果只剩几个漂亮框，主视觉还没成立。
保留必要的对象名、单位、条件与结论，不能把“少字”做成猜谜。

## 场景连续性与动作层次

- 同一 scene 的对象保持身份、相对位置与已知状态。step 只推动它；不要给整场 `key={step}` 让所有元素重演入场。
- 相邻镜头写一条交接：保留哪个对象/方向/颜色，何时让出焦点。转场允许硬切，避免为了连贯强行把无关对象 morph。
- 一次主要动作、少量跟随反馈、稳定背景。必要时用 anticipation→action→settle，但短 cue 直接给结果，不强加预备动作。
- 先后动作来自真实 cue，不按字数估算已提供的 SRT。SRT 只能精确到 cue 起点，句内重点需听音频或更细对齐；不能宣称逐字同步。
- 让信息在被说到时可辨认。可预露中性容器/已知对象；不得提前揭晓结果。不要把“通过”的翻面拖到该句结束。
- 揭示完成后留阅读时间，通常至少约 0.8 秒，视信息量调整。没有新信息时可以静止；**取消“末拍必须落在 75%–90%”**。短步容纳不下时简化动作或合并场景，不修改原音频节奏。
- 高成本效果先降采样观察：大面积 blur、动态阴影、粒子、3D 不叠满全屏。运动以 transform/opacity、SVG 几何为主，实际播放验证掉帧。

## 文案、卡片与高级感

正文优先转成对象、关系、数据与真实证据。每屏保留一个题眼；装饰性英文、重复序号、口播复述优先删除。
卡片不是默认布局：比较台、证据片、文件、对象状态可用卡片；短观点不必装进圆角框。保留有内容身份的差异，用统一材质、线宽、光向与对齐统一全片。

默认尝试主标题 80–140px、重要标签 32–48px、来源注释 24–28px（1920 舞台）；这些是起点，按真实画面调整。不要全片大字当主视觉。手机宽度缩到约 480px 时仍能认出主对象、关系与结论。

主物体应占据足够画幅，留白围绕视觉中心；不用“左右必须对称/必须填满 88%”限制构图。背景纹理应在缩小后退到主体后面，不能降低对比度。纯黑/白、编辑式留白、偏心构图都可以成立。

## 素材与真实性

- 数据、排名、引用、技术名称对应 plan 的事实表；核对截图含表头与单位。示意比例标“示意”。
- 图片/视频缺失可以预览占位，但交付必须替换、省去或明确说明缺口，不能把 placeholder 当完成。
- 真实证据可以比普通镜头字多：先展示归属，再裁切聚焦结论。不可裁掉改变解释的条件。
- 图标表达对象身份；品牌用用户已有/官方资产。SVG 自绘机制图不冒充真实界面。

## 工程契约

- `ChapterStepProps.step` 为焦点状态；`time` 是可选的章内秒数。连续 MG 用 [MOTION.md](MOTION.md) 的时钟与采样函数；旧式 CSS 入场可保留，但不能宣称它能任意 seek。
- 固定 px；颜色/字体家族使用 tokens.css 已定义 token。允许 `currentColor` / `transparent`。不要写未定义变量。
- 全章类名使用 BRIEF 分配前缀。共享组件由主线程放 `src/components` 或 `src/motion`；章节不相互导入。
- narrations 数量和 plan 一致；step 增删回 plan 再生成。最后一步要显式分支以便旧扫描器核对；数据驱动分支若扫描 SKIP，浏览器必须覆盖全部 step。
- 可交互控件加 `data-no-advance`。无章节 setTimeout/setInterval；底层唯一时钟允许 rAF。

## 安全区与验收

以 1920×1080 舞台为准，边缘一般留 100px 左右。头像配置后留对应角 432×432 作为保守避让；如用圆形精算，圆心距角边 216px、关键内容距圆心至少约 200px。底部字幕启用时 y≥915 不放关键信息。背景可贯穿。

先运行 `npm run check`，再按 [EVALUATION.md](EVALUATION.md) 用 ego-browser 查起态、动作中点、结果、下一镜头。报告具体截图/时间、播放结果、仍缺的证据。不以代码检查或单张封面代替视觉验收。
